# 使用说明

本文覆盖界面元素、手势、菜单与按键行为。容器的创建与管理见 [containers.md](containers.md)。

## 界面构成

启动后是一个占满屏幕的终端，加三条界面元素：

| 位置 | 内容 |
|---|---|
| 顶栏左侧 | 模式 chip（`本地` / `容器` / `容器与镜像`），点一下切换模式或进入容器管理 |
| 顶栏中部 | 状态行：`行列数 · 字号 · pid`，只描述终端几何，不重复模式名 |
| 顶栏右侧 | `⋮` 应用菜单 |
| 底部键条 | 常用键一行 + 两个图标键，仅在触屏时存在 |

全屏模式下顶栏收起，菜单入口只剩长按 `⋯`。

## 键条

```
CTRL  ALT  ESC  TAB  ^C  ←  ↑  ↓  →  ⋯  ⌨  ⛶
```

- `CTRL` / `ALT` 是一次性修饰键，只作用于下一次按键；锁定期间整键反白，避免忘记解锁后输入全变控制字符。再次点击取消。
- `⋯` **单击**展开更多键面板（`HOME` `END` `PGUP` `PGDN` `DEL` `INS`、`F1`–`F6`），面板内的键发送完整转义序列，不叠加粘滞修饰。
- `⋯` **长按**打开应用菜单（全屏下没有顶栏，这是唯一入口）。
- `⌨` 展开自绘键盘，在上方的全键盘与下方的 `?123` 数字/符号页之间切换。
- `⛶` 进入全屏。
- 键条不横向滚动：常用键等宽铺满一行，低频键进面板。

## 手势

| 操作 | 行为 |
|---|---|
| 上下拖动 | 查看 scrollback（3000 行）；上滚时右下角浮出「↓ N 行 · 回到底部」胶囊，点击回到光标 |
| 双指捏合 | 调整字号（持久化） |
| 单指点击终端 | 请求输入焦点、按需弹出软键盘 |
| 双指上下滑 | 程序开启鼠标上报时转为滚轮序列（vim、htop 可翻页） |

## 物理键盘

接入蓝牙或 USB 键盘后，键条与 `⌨` 按钮自动消失，终端多出一行高度；热插拔实时生效。

冷启动时输入焦点直接落在终端上，`Enter` 进 PTY，不会先激活顶栏按钮。按键在输入法之前被截获并翻译为 xterm 序列，映射表见 [internals.md](internals.md#物理键盘映射)。

## 菜单

| 项 | 说明 |
|---|---|
| 重启当前会话 | 结束并重建当前模式的会话 |
| 复制全部输出 / 复制当前屏 | 全量文本 / 仅可见屏内容 |
| 粘贴 | 多行内容会先确认；程序开启括号粘贴时用 `ESC[200~ … ESC[201~` 包裹 |
| 清屏 | 清空屏幕，保留 scrollback |
| 字号 + / - | 同双指捏合 |
| Root Shell：开/关 | 本地模式是否用 `su -c` 提权启动 |
| 容器运行时：PRoot / Docker | 切换容器后端，Docker 为实验性 |
| 容器管理 | 图形界面：新建 / 启动并切换 / 停止 / 删除 / 拉镜像 / 导入 tar / 删镜像 |
| 容器管理控制台 | docker 语法子集的命令行界面 |
| 导入镜像 | 选择 `docker save` / `docker export` / OCI 归档 |
| 重建当前容器 | 清空容器 rootfs 并重新物化 |
| 绑定目录 | 管理宿主目录到容器路径的映射 |
| 存储权限 | 申请 `MANAGE_EXTERNAL_STORAGE`，用于访问 `/sdcard` |
| 全屏模式 | 隐藏顶栏与状态行 |
| 帮助 | 在浏览器打开本文档 |
| 关于 | 版本、能力边界说明 |
| 退出应用 | 结束会话与所有子进程，有二次确认 |

## 会话结束

进程退出（`exit`、`Ctrl-D`、崩溃）后，键条区域替换为会话结束条：

- `会话已结束 (exit 0) · 输出仍在屏上`，正常退出为灰色，被信号杀死（`128+n`）或异常码为橙色；
- 提供「复制输出」与「重启」两个动作；
- 终端最后几行输出原样保留，不被结束条遮挡；
- 对已退出的 PTY 敲键盘会提示改用下方重启。

## 返回键

返回键按层退出，不会杀死会话：

1. 收起更多键面板；
2. 收起软键盘；
3. 全屏状态下退出全屏；
4. 退到后台（会话保持，回来仍在原处）。

真正结束会话走菜单「退出应用」。
