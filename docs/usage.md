# 使用说明

本文覆盖界面元素、手势、菜单与按键行为。容器的创建与管理见 [containers.md](containers.md)。
实现原理、构建发布、测试清单等开发者文档收在 [dev/](dev/) 下。

## 界面构成

启动后是一个占满屏幕的终端，加三条界面元素：

| 位置 | 内容 |
|---|---|
| 顶栏左侧 | 模式 chip（`本地` / `容器` / `容器与镜像`），点一下切换模式或进入容器管理 |
| 顶栏中部 | 状态行：`行列数 · 字号 · pid`，只描述终端几何，不重复模式名 |
| 顶栏右侧 | `⋮` 应用菜单 |
| 底部键条 | 常用键一行 + 两个图标键，仅在触屏时存在 |

全屏模式下顶栏收起，菜单入口只剩长按 `⌨`。

## 键条

```
CTRL  ALT  ESC  TAB  ^C  ←  ↑  ↓  →  ⌨  ⛶
```

- `CTRL` / `ALT` 是一次性修饰键，只作用于下一次按键；锁定期间整键反白，避免忘记解锁后输入全变控制字符。再次点击取消。
- `⌨` 展开辅助键盘，与系统输入法同屏组合使用。字母/数字/常用标点由系统输入法负责（点一下终端即弹出）；辅助键盘只放系统键盘不提供或翻页成本高的键：
  - **固定区（不可自定义）**：编辑键 `HOME` `END` `PGUP` `PGDN` `DEL` `INS`、`F1`–`F12`，发送完整转义序列，不叠加粘滞修饰；
  - **可自定义区（默认键集）**：控制字符 `^A ^D ^E ^K ^L ^R ^U ^W ^Y ^Z ^\`、shell 符号 `| & < > ( ) [ ] { } $ \` ~ \ ; : " ' = * /`。长按任意键可编辑/删除（默认键删除后可找回）；点「＋」添加自定义键——一个键 = 一串步骤，每步六种动作任选，详见下文 [自定义键](#自定义键)；自定义键数量不限，超过行数上限（菜单「辅助键盘行数」可调，默认 4 行）时该区竖向滚动，新添加的键自动滚到底部可见；长按「＋」或菜单「辅助键盘：恢复默认键集」恢复出厂键集；
  - 粘贴由系统输入法的剪贴板子菜单承担，键上不再重复。
- `⛶` 进入全屏。
- 功能键（`⌨` `⛶` `＋`）不发字符、只做控制动作，绿描边淡绿底与输入键区分；激活态（键盘展开/全屏中）文字转绿。
- 键条不横向滚动：常用键等宽铺满一行，更多键在辅助键盘固定区。

## 自定义键

点辅助键盘的「＋」新建、长按已有键编辑。一个自定义键 = **按序执行的步骤序列**；
标签留空时按第一步自动生成（如 `^U↵`）。每步从下表六种动作中选一：

| 动作 | 功能 | 填什么 | 示例 |
|---|---|---|---|
| 文本 | UTF-8 原样直发，任意 Unicode，可整段 | 任意字符串 | `ls -la`、`docker compose up -d`、中文短语 |
| `^X` | 单个控制字符：字节 = 字符 & 0x1f，与 xterm 的 Ctrl 组合一致 | ASCII 字母、`\`、标点 `@ [ ] ^ _ ?`、空格 | `u`→^U（清行）、`]`→^]（vim tag 跳转）、`?`→DEL（删前字符）、`@`→NUL |
| ESC | 先发 ESC 再发值 | 任意字符串，**留空 = 裸 ESC** | 留空（vim 退插入模式）、`[H`（光标归位）、`[A`（↑） |
| 字节 | 按 1–2 位十六进制发单个原始字节 | `00`–`ff` | `1b`=裸 ESC、`7f`=DEL、`00`=NUL、`0d`=CR |
| 回车 | 发 CR（0x0d），与物理键盘 Enter 同字节 | 无需填写 | 宏的收尾执行 |
| 延迟 | 先冲刷已攒字节，等 N 毫秒再继续 | 1–10000 毫秒 | 给慢命令留节拍 |

**执行语义**：步骤按序执行，无延迟的相邻步骤合批发送（一次写进 PTY），
延迟步骤把前面的字节先冲出去再等待。典型组合：
`^U + ls -la + 回车` = 一键清行并执行；`回车 + 延迟 300 + echo ok + 回车`
= 等上条跑完再执行下一条。

**同一含义多种写法时怎么选**——发送性能没有差别（单字节、能合批），差别在
可读性、自动标签与覆盖面，按下面的优先级选：

1. **控制字符首选 `^X`**：语义直白、标签自动（`^]`）、输错有校验提示。
   `^X` 覆盖不了的才用字节模式兜底——Ctrl+数字类方言映射（如 Ctrl+2=NUL）
   各实现不一致，`^X` 有意不收，需要时写字节（`00`）；表外任意字节同理。
2. **裸 ESC 三处可选，推荐「ESC 留空」**：语义最明确，标签就是 ESC；
   `^X` 填 `[` 等价；字节 `1b` 是兜底。**ESC + 序列**（`[H`、`[200~`）
   只能用 ESC 模式——`^X` 只发单字节。
3. **回车用「回车」动作**，不要用文本填 `\r`——文本模式按字面 UTF-8 发送，
   会发出 `\` 和 `r` 两个字符。
4. **NUL/DEL**：`^X` 的 `@`/`?` 优先（可读），字节 `00`/`7f` 兜底。

## 手势

| 操作 | 行为 |
|---|---|
| 上下拖动 | 查看 scrollback（3000 行）：手指下滑看更早内容（内容跟手），松手带惯性滑行；离开底部后右下角浮出「↓ N 行 · 回到底部」胶囊，点击回到光标 |
| 双指捏合 | 调整字号（持久化） |
| 单指点击终端 | 请求输入焦点、按需弹出软键盘；**有选区时改为清除选区**（再点一次才弹键盘） |
| 长按 | **选区**：长按即按词选中（空白 / 标点为边界，中文逐字；词内轻抖保持整词），拖动按字符扩展（可跨屏幕与 scrollback），拖到屏幕上/下边缘自动滚动；松手后选区两端出现手柄，可拖拽微调边界。浮动条「复制 / 全选 / 取消」贴着选区显示（上方空间不足时转到下方） |
| 双指上下滑 | 程序开启鼠标上报时转为滚轮序列（vim、htop 可翻页） |

选区细节：

- 复制语义与桌面终端一致：autowrap 折行的相邻行拼回一个逻辑行（长 URL/命令复制出来不折断）、每行行尾空白剥除、组合字符随主格保留；
- **长按即选词**：按住就选中触点所在的词（空白与标点是边界，`/data/local/tmp` 长按选 `local`；中文/emoji 逐字），不用先拖一下；词内轻抖仍保持整词，拖出词外才按字符扩展；
- **在已有选区上长按 = 端点增减**（xterm extend-selection）：锚固定在离触点较远的端点，拖动挪最近的端点——往选区外拖是扩大、往里拖是缩小，同一手势；
- **两端手柄**：起点/终点各有一个水滴手柄，按住手柄拖动即可微调边界，手指不会挡住边界格；浮动条跟随选区中点水平居中，不固定在屏幕顶部；
- 任意按键或粘贴会结束选区（xterm 惯例：key press discards selection）；
- 程序开启鼠标上报时（vim `set mouse=a`）触摸归程序，长按不进选区——程序优先；
- 接硬件键盘时 **Shift+按下拖动** 走本地选区（xterm 的 shift override 惯例，鼠标上报模式下同样生效）：有选区时挪最近的端点（增减），没有则从触点起新选区。

## 程序写剪贴板（OSC 52）

终端里的程序也能把文本直接写进系统剪贴板——vim 用 `"+y` 复制、tmux 的
copy-mode 复制，桌面终端靠的就是这条通道（OSC 52）。本应用默认**关闭**，
需要时在菜单「设置 → 程序写剪贴板：开/关」打开：

- 打开后，程序发出的 OSC 52 序列会写入系统剪贴板，并弹 toast「程序已写入剪贴板（N 个字符）」；
- 默认关是刻意的：终端里跑的任何脚本（包括来路不明的安装脚本）都能借此摸到剪贴板，与 Termux 对剪贴板外部访问的同一条安全界线；
- **只写不读**：程序不能通过它读取剪贴板内容（vim `"+p` 读不到，粘贴请用输入法剪贴板或应用「粘贴」）；
- 只认系统剪贴板（xterm 的 `c` 目标），单次内容超过 64KB 会截断。

典型用法（vim）：`"+yy` 复制当前行到系统剪贴板，之后在其它应用直接粘贴。

## 物理键盘

接入蓝牙或 USB 键盘后，键条与 `⌨` 按钮自动消失，终端多出一行高度；热插拔实时生效。

冷启动时输入焦点直接落在终端上，`Enter` 进 PTY，不会先激活顶栏按钮。按键在输入法之前被截获并翻译为 xterm 序列，映射表见 [dev/internals.md](dev/internals.md#物理键盘映射)。

标准键位（xterm / GNOME Terminal 同款）：

| 键位 | 行为 |
|---|---|
| `Ctrl+Shift+C` | 复制：有选区复制选区，没有则复制当前屏 |
| `Ctrl+Shift+V` / `Shift+Insert` | 粘贴（多行先确认，括号粘贴照常生效） |
| `Ctrl+Shift+A` | 全选 |
| `Shift+PgUp` / `Shift+PgDn` | 本地滚动一页（终端自己的视口，不发程序）；带 Ctrl/Alt 时仍按修饰序列发给程序 |
| `Ctrl+空格` | 先交给输入法；不响应时发送 `0x00`（安卓平台上它是系统「键盘布局切换」快捷键，语义见下方「中文等输入方案」） |

### 中文等输入方案

**软键盘触摸输入**（实测可用）：字母键走输入法组词 → 选词上屏（`commitText`），与系统文本框同一条通路；中文、俄文、日文假名等由输入法处理，应用侧无需切换模式。

**外接硬件键盘打中文**（实测可用，2026-11-20，搜狗 + 蓝牙键盘）：接上蓝牙/USB 键盘后，字母键直接进输入法组词，和在便签里用同一个键盘打中文一样——空格选词，上屏的词逐字节进命令行。要满足两个条件：

- 系统「设置 → 语言和输入法 → 物理键盘 → 使用屏幕键盘」打开。候选栏不出现时应用不接管键盘，免得你盲挂着拼音打完工才发现；
- 输入法界面看得见。看不见就**双击 Shift** 叫出来并开始组词，再双击一次退回字母逐键直发。
- **输入法处于拼音 9 键或 26 键布局**。双击 Shift 的「切中英」只在拼音键盘下成立；处于英文、五笔、手写等其它输入方案时，这个手势不会按预期切换，不能据此判断接管失效。
- 物理键盘的键位映射完全由输入法决定（拼音、注音、五笔等由输入法自行解释），应用不做键位假设；若某个输入方案不支持外接键盘（如搜狗注音提示「当前键盘不支持外接键盘输入」），它会自行提示并退回按键。
- 实测（搜狗小米版）：26 键拼音、9 键拼音、五笔、手写可用（9 键候选计算较慢，输入字母后稍等再按空格）；注音、笔画不可用。

菜单「键盘与输入法 → 外接键盘中文输入」是三档策略：「自动」跟输入法界面可见性走（默认，双击 Shift 在这档生效）；「始终交给输入法」给把候选画在自己窗口里的输入法，盲打风险自担；「从不」就是老行为——硬键盘字母永远直发，中文靠软键盘点。连打大写（两下 Shift 中间敲过别的键）和间隔超过半秒的两下都不算双击。

组词期间按键归谁（实测）：

| | 空闲 | 挂着拼音 |
|---|---|---|
| `Enter` | 执行命令 | 交给输入法上屏（搜狗把拼音原样上屏，不会带着 CR 把命令执行掉） |
| `空格` | 直发 | 选词 |
| `退格` | 直发 | 删拼音 |
| `Esc` / `Tab` / 方向键 / `Ins` / `Del` / `F1`–`F12` | 输入法不消费、原样退给应用，照常直达终端 | 同样直达终端，但**不取消组词**（实测 `Esc` 之后按空格仍选词上屏）；vim 想退插入模式得先把拼音选掉或删干净 |
| `Ctrl`/`Alt` 组合 | 直达终端 | 直达终端（组词期间也能发 `Ctrl+C`） |

想先看清当前归哪档：屏幕键条收着、终端底部有输入法界面 = 组词中。

- 也可以先在别处打好中文，再用菜单「粘贴」送进终端；
- `Ctrl+空格` 在安卓上是「物理键盘**字符布局**切换」的系统快捷键（仅当该键盘配了 ≥2 个布局才由系统接管），不是输入法的中英切换；只配一个布局时落到应用，不消费则发 `0x00`。

**切换输入法**（菜单 → 键盘与输入法）：

- 「切换输入法…」弹出系统选择器——安卓不允许普通应用静默切换输入法（系统 API 限定），只能由用户在弹窗确认；终端场景实用：搜狗 ↔ 无联想输入法来回切；
- 「输入法设置…」跳系统「管理输入法」启用页——选择器只列出已启用的输入法，只启用了一个时先来这里再启用一个；
- 系统布局切换的配置入口：设置→系统→语言和输入法→物理键盘→选中你的键盘→添加布局。

## 菜单

菜单按 7 组组织：会话 / 屏幕内容 / 键盘与输入法 / 容器 / 外观 / 设置 / 帮助（横屏 360dp 高度下平铺放不下，二级首行是绿色组名，点它或按返回键回上一层；键盘/输入法相关五项原本分散在「屏幕内容」与「设置」两处，已收进独立的「键盘与输入法」组）。组内各项：

| 项 | 说明 |
|---|---|
| 重启当前会话 | 结束并重建当前模式的会话 |
| 复制全部输出 / 复制当前屏 | 全量文本 / 仅可见屏内容（要复制某个 URL/token 请用长按选区，见「手势」） |
| 粘贴 | 多行内容会先确认；程序开启括号粘贴时用 `ESC[200~ … ESC[201~` 包裹 |
| 清屏 | 清空屏幕，保留 scrollback |
| 切换输入法… | 弹出系统输入法选择器（安卓不允许普通应用静默切 IME，见「切换输入法」） |
| 输入法设置… | 跳系统「管理输入法」启用页 |
| 外接键盘中文输入：自动/始终/从不 | 外接键盘字母是否交给输入法组词的三档策略，详见「中文等输入方案」 |
| 辅助键盘：恢复默认键集 | 辅助键盘恢复出厂键集：删除过的默认键找回，添加的自定义键清空 |
| 辅助键盘行数：最多 N 行（超出滚动） | 可自定义区最多占几行（默认 4，输入 0–10，留空或 0 = 不限）。自定义键数量不设上限：超过行数上限时该区竖向滚动，固定区与键条高度不变，终端不被顶走。改动即时生效 |
| 容器运行时：PRoot / Docker | 切换容器后端，Docker 为实验性 |
| 容器管理 | 图形界面：新建 / 启动并切换 / 停止 / 删除 / 拉镜像 / 导入 tar / 删镜像 / 镜像源设置 |
| 容器管理控制台 | docker 语法子集的命令行界面 |
| 导入镜像 | 选择 `docker save` / `docker export` / OCI 归档 |
| 重建当前容器 | 清空容器 rootfs 并重新物化 |
| 绑定目录 | 管理宿主目录到容器路径的映射 |
| 全屏模式 | 隐藏顶栏与状态行 |
| 字号 + / - | 同双指捏合 |
| 终端字号范围：6–28sp | 捏合与字号 ± 的上下限（默认 6–28，允许最小 2–36、最大 4–72）。竖屏 80 列放不放得下由「屏宽 × 字号」决定——同为最小字号，有的机型溢出折行、有的还有富余，窄屏机可把下限调低。一个对话框两个输入框，改动即时生效：区间收窄时当前字号自动夹回区间内 |
| Root Shell：开/关 | 本地模式是否用 `su -c` 提权启动 |
| 程序写剪贴板：开/关 | 允许程序经 OSC 52 写系统剪贴板（vim `"+y` 等），默认关，详见「程序写剪贴板（OSC 52）」一节 |

## 会话结束

进程退出（`exit`、`Ctrl-D`、崩溃）后，键条区域替换为会话结束条：

- `会话已结束 (exit 0) · 输出仍在屏上`，正常退出为灰色，被信号杀死（`128+n`）或异常码为橙色；
- 提供「复制输出」与「重启」两个动作；
- 终端最后几行输出原样保留，不被结束条遮挡；
- 对已退出的 PTY 敲键盘会提示改用下方重启。

## 返回键

返回键按层退出，不会杀死会话：

1. 收起软键盘；
2. 全屏状态下退出全屏；
3. 退到后台（会话保持，回来仍在原处）。

真正结束会话走菜单「退出应用」。
